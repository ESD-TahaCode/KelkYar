# 🎨 کلک‌یار | KelkYar

### استودیوی آنلاین طراحی و تایپوگرافی فارسی

**کلک‌یار** یک استودیوی طراحی تحت وب و متن‌باز است که با الهام از نرم‌افزار Kelk توسعه داده می‌شود. هدف این پروژه، فراهم کردن محیطی ساده و کاربردی برای طراحی متن، تایپوگرافی فارسی و خلق آثار نوشتاری در مرورگر وب است.

ما تلاش می‌کنیم تجربه‌ای خلاقانه، در دسترس و قابل توسعه برای طراحی نوشتار فارسی فراهم کنیم. ✨

## 🛠️ فناوری‌ها

این پروژه با استفاده از فناوری‌های زیر ساخته شده است:

- **HTML5** — ساختار صفحات وب
- **CSS3** — طراحی رابط کاربری و استایل‌ها
- **JavaScript** — منطق برنامه و تعاملات

## 🚀 راه‌اندازی پروژه

ابتدا مخزن را دریافت کنید:

```bash
git clone https://github.com/ESD-TahaCode/KelkYar.git
```

سپس وارد پوشه پروژه شوید:

```bash
cd KelkYar
```

در نهایت، فایل `index.html` را در مرورگر باز کنید یا برای اجرای پروژه از افزونه Live Server در VS Code استفاده کنید.

*اگر پروژه به قابلیت‌های سرور یا تنظیمات دیگری وابسته باشد، مراحل راه‌اندازی متناسب با آن به‌روزرسانی خواهند شد.*

## 🤝 مشارکت در پروژه

کلک‌یار یک پروژه تیمی است و از پیشنهادها، ایده‌ها و مشارکت‌های سازنده استقبال می‌کند.

برای مشارکت در توسعه:

1. مخزن را Fork کنید.
2. یک شاخه جدید برای تغییرات خود بسازید.
3. تغییراتتان را اعمال و Commit کنید.
4. یک Pull Request ارسال کنید.

لطفاً پیش از اعمال تغییرات گسترده، پیشنهاد خود را با تیم مطرح کنید.
